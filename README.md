# GLASSFALL · 글래스폴

유리의 균열을 연결해 연쇄 파쇄를 만드는 모바일 낙하 퍼즐입니다. 기존 젤리 퍼즐의 코드, 스테이지, 이미지 및 관련 스크립트는 현재 트리에서 제거했습니다. 이전 버전은 Git 이력에 남습니다.

## 실행과 배포

- 실행 파일: `dist/index.html` 및 같은 폴더의 JS/CSS. 정적 호스팅 출력 폴더는 `dist`이며 빌드 명령이 필요 없습니다.
- 루트 `index.html`은 `dist/`로 연결됩니다. 런타임 외부 의존성 및 외부 리소스가 없습니다.
- 로컬 확인: `python -m http.server 8080 --directory dist`
- 검증: `node --test tests/*.test.cjs` 및 `node --check dist/app.js`

## 규칙

10열 × 20행 보드에서 7종 조각을 이동·회전·보관합니다. 가로줄을 채우면 해당 줄에서 균열이 전파됩니다. 양쪽 셀의 흰 균열 끝이 모두 맞닿아야 전파되며 색은 무관합니다. 삭제 대상은 중력 적용 전 보드에서 확정합니다. 파쇄 후 열마다 남은 유리가 떨어지고, 다시 완성된 가로줄은 다음 연쇄로 계산합니다. 시각적 파편은 판정에 영향을 주지 않습니다.

조작: ←/→ 이동, ↑ 또는 X 회전, ↓ 천천히 내리기, Space 즉시 낙하, C 보관, P/Escape 일시정지.

모바일은 **게임판 또는 하단 스와이프 영역**에서 조작합니다.

- 좌우 스와이프: 이동. 짧게 쓸면 한 칸, 길게 밀면 이동 거리에 맞춰 여러 칸 이동합니다.
- 짧게 터치: 손을 뗄 때 한 번 회전합니다. 연달아 톡톡 터치하면 각각 회전합니다. 위 스와이프와 길게 누르기는 회전하지 않습니다.
- 아래로 빠르게 쓸고 떼기: 즉시 낙하합니다. 손을 떼기 전 착지 테두리와 안내가 강조됩니다.
- 천천히 아래로 밀기: 거리에 맞춰 천천히 내립니다. 느린 드래그 도중 빠르게 움직여도 즉시 낙하로 바뀌지 않습니다.
- 보관은 별도 버튼이며, 보조 좌우·낙하 버튼은 ‘버튼 조작’을 펼치면 나타납니다.

한 번의 접촉은 처음 인식한 가로 또는 세로 방향을 유지합니다. 탭 회전은 300ms 이내, 접촉 전체의 최대 이동 거리 10 CSS px 이내일 때만 실행합니다. 스와이프 후 원위치로 돌아와도 회전하지 않으며 새 동작은 손을 뗀 뒤 시작합니다. 가로 이동은 블록을 통과하지 않고, 벽에 막힌 이동량을 누적하지 않습니다. 650ms 잠금 유예와 제한된 잠금 연장이 있으며 창을 떠나면 자동 일시정지합니다.

## 모드와 기록

- 균열 연구실: 배치·균열·연쇄 3장, 총 9개 고정 퍼즐. 자동 낙하와 시간 제한이 없으며 정해진 조각만 사용하고 보관은 하지 않습니다. 목표 달성으로 다음 연구가 열리고, 기준 조각 수 이내 성공과 남은 유리 없는 성공에 별을 추가로 받습니다. 총 27별, 최고 별/최소 사용 조각/최고 연쇄는 기기에 저장됩니다. 실마리는 별을 차감하지 않습니다.
- 3분 도전: 180초 동안 점수 경쟁. 시간 종료 시 진행 중인 파쇄 연쇄까지 정산합니다.
- 무한 모드: 줄 제거에 따라 레벨과 낙하 속도가 올라갑니다.
- 오늘의 도전: 한국 날짜 기준 같은 시드, 3분 제한. 온라인 순위표는 없습니다.
- 균열 연습: 준비된 첫 배치로 원리를 배웁니다. 기록에 포함되지 않습니다.
- 자유 플레이 결과에는 모드별 최고 연쇄·균열 파쇄 기록과 직전 동일 시드 판의 점수 차이를 표시합니다.
- 같은 판 재도전은 조각과 균열 순서를 재현합니다. 최고 점수와 3개 숙련 배지는 기기 내 저장이며 계정 동기화는 제공하지 않습니다.

## 구현 범위

이 버전은 앞서 제안한 소재 중 **유리 균열**의 첫 구현입니다. 모래·젤리·물 등 다른 소재, 능력 선택, 공유 퍼즐, 네이티브 Android 패키지는 포함하지 않습니다. 회전은 간단한 벽 보정 방식이며 공식 Tetris 규격 구현을 표방하지 않습니다.

게임 규칙, 난수 재현성, 연쇄, 조작 이벤트와 화면 초기화는 자동 검증합니다. 실제 휴대폰 터치감·프레임 성능은 사용 기기에서 확인해야 합니다.

## 조작 개선

이동·낙하는 스와이프, 회전은 짧은 터치로 조작합니다. 위치 선택 막대와 별도 회전 버튼은 제거했습니다. 가로 이동의 칸 경계 흔들림과 원위치 복귀 오차를 완화했습니다. 방향 고정, 속도·거리 판정, 손을 뗄 때 낙하 확정으로 이동 중 의도하지 않은 낙하를 줄입니다. 취소된 접촉, 두 번째 손가락, 조각 교체 전 접촉이 다음 조각을 떨어뜨리지 않도록 처리했습니다.

자동 검증은 실제 입력 핸들러를 최소 DOM 어댑터에서 실행합니다. 짧고 긴 이동, 왕복, 회전, 빠른 낙하, 느린 하강, 되돌리기, 취소, 접촉 소유권 및 연습 완료를 확인합니다. 실제 기기의 브라우저 레이아웃이나 터치감을 검증한 것은 아닙니다.

## 다음 단계: 균열 연구실

점수 반복 외에 배치 목적과 다음 해답을 제공하는 첫 도전 묶음입니다. 1~3은 가로/세로/두 조각 배치, 4~6은 균열 전파/갈래/균열 방향 회전, 7~9는 낙하 후 2연쇄와 두 수 준비를 다룹니다. 각 연구의 3별 해답을 엔진에서 검증하고, 실제 UI 입력 핸들러로 9개 순차 완료·해금·재접속 복원·실패·다시하기까지 자동 검증합니다.

별 세 가지 조건은 독립적으로 평가합니다. 목표 달성이 필수이며, 성공 결과의 사용 조각과 남은 유리로 추가 별을 받습니다. 목표 평가는 마지막 조각의 모든 파쇄/낙하가 끝난 뒤 수행하며, 낮은 별로 재도전해도 최고 기록을 덮어쓰지 않습니다. 진행은 기존 저장 키 안에 추가되어 이전 최고 점수와 배지를 보존합니다.

현재 ‘모든 완성줄 동시 제거 + 열 전체 압축’ 규칙에서는 한 번의 낙하가 만드는 파쇄 파동은 최대 2회입니다. 따라서 연구실은 불가능한 3연쇄 목표를 두지 않고, 2연쇄의 총 제거 줄 수와 준비 배치로 난도를 높입니다. 9개 연구는 첫 학습/재도전 콘텐츠이며 주간 도전·온라인 경쟁·새 소재까지 구현한 것은 아닙니다.
