# Flower Bloom 1차 재미 강화

기준: `main`의 `156126760e44a2031783292ad8cefa9d5e3174f7`.
단일 HTML의 기존 구현을 수정했으며, 24개 인라인 이미지 데이터와 `assets/`는 그대로 유지했다.

## 변경 내용

- 일반 / 2–4 / 5–7 / 8+ 콤보별 꽃잎, 개화 크기, Glow, 진동을 차등 적용한다. 큰 글자는 보드 위 여백, 최신 점수/PERFECT는 아래 여백에 표시한다. 5+ 콤보는 보드 외곽 파동을 사용한다.
- 같은 꽃 8콤보를 만든 개화부터 5초간 BLOOM MODE. 기존 계산 점수에 1.5를 곱한 후 정수 반올림한다. 자체 시간 보너스는 없다.
- 실패나 다른 꽃으로 전환해도 만개 잔여 시간은 유지된다. 한 체인에서는 한 번만 발동한다. 새 체인의 8콤보는 그 시점부터 새 5초를 시작하며 남은 시간에 더하지 않는다.
- 메뉴/백그라운드 일시 정지는 만개 잔여 시간을 보존한다. 개발자 패널의 **타이머 정지**는 기존 게임 타이머만 멈춘다. 클리어/종료/재시작/스테이지 이동은 만개를 종료한다.
- `spawn(index)`는 자연 랜덤 70%, 목표 보정 20%, 연속 개화 기회 10%를 기본으로 한다. 목표 보정은 기존 색 개수/미완성 목표에 실제 인접쌍 부족과 생성 위치의 이웃을 추가로 고려한다. 모든 색은 항상 선택될 수 있다. 초기 `build()`는 기존 자연 랜덤을 유지한다.
- 18px 미만 터치와 재생성 중인 목적지는 무시한다. 같은 색으로의 유효 스와이프와 보드 바깥 방향 스와이프는 실패로 유지한다. 탭 합성은 추가하지 않았다.
- reduced motion에서는 꽃 확대/흔들림/파동/입자/진동 없이 상태와 숫자를 표시한다.

```powershell
# Playwright가 설치된 환경에서 실행. Chromium 대신 로컬 Chrome을 사용할 때만 설정.
$env:CHROME_PATH = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node tests/bloom-regression.cjs
```

25개 검사 통과: 조합 순서/인접성, 콤보/시간 상한, PERFECT, 만개 점수/만료/체인 재발동/메뉴 정지, 즉시 클리어, 리셋 콜백 취소, 종료, 개발자 조작, Chromium 터치 입력, 인접쌍 집계, 시드 고정 확률 표본, 효과 정리, reduced motion, 320×568 / 360×740 / 412×915 레이아웃. 인라인 JS 문법 및 브라우저 런타임 오류 없음. 기준 파일과 24개 인라인 이미지 데이터의 SHA-256을 비교해 동일함을 확인했다.

## Android 실기기 확인

- 빠르게 2→5→8콤보를 이어갈 때 진동 차이, 숫자 가독성, 프레임 저하와 다음 색 식별.
- 짧은 탭, 미세 움직임, 네 방향 합성, 가장자리 바깥 스와이프, 재생성 중인 칸, 멀티터치/제스처 취소.
- 만개 중 다른 꽃/실패, 5초 만료, 같은 체인 9+ 재발동 방지, 새 체인 8 재발동.
- 앱 전환/복귀와 메뉴 정지, 시간 종료/재시작/개발자 스테이지 이동, 여러 목표와 즉시 클리어.
- Android의 모션 감소 설정, 실제 진동 지원, 주소 표시줄 변화에 따른 세로 화면 배치.

## 영향과 남은 기술 부채

점수와 생성 분포가 달라져 기존 기록/체감 난이도의 비교가 필요하다. 1스테이지는 목표가 보라꽃 8개이므로 목표꽃 8콤보와 동시에 즉시 클리어되는 것이 정상이다. 만개를 길게 시험하려면 2스테이지에서 보라꽃 등 미완료 목표 외 꽃의 체인을 사용한다.

수정한 기존 문제: 짧은 터치와 busy 목적지에서 콤보 초기화, 중앙 콤보/PERFECT 겹침, 전체 화면 밝기 애니메이션의 reduced-motion 누락, 앞선 효과 정리 콜백이 재사용된 칸의 새 Glow를 지우는 경쟁 상태.

기존 게임 시간은 여전히 100ms 간격마다 0.1초를 빼므로 느린 기기의 타이머 지연에 영향을 받을 수 있다. 만개만 단조 시계(`performance.now`)를 사용한다. 개발자 목표 +/-는 기존처럼 `ST`를 직접 수정한다. 실기기 진동과 저사양 Android의 성능/재미는 브라우저 자동 검사로 확정할 수 없다.
