# CRAYON BLOOM — 장난블록 본게임 통합

2026-09-29 · 기준 main `c1adbb8d1b0025496ead3a7d22043310c32ae829`

사용자가 실험실로 분리하지 말고 본게임에 적용하도록 요청했다. 이전 실험실 전용 제한은 이번 요청으로 변경됐다.

## 실제 본게임 변경

- `dist/index.html`에서 네 장난블록의 동작·그리기·본게임 연결 모듈을 직접 불러온다. 앱 캐시는 `cb-toy-main1`이다.
- 튜토리얼 이후 정식 새 게임의 첫 블록은 통통이다. 활성 플레이 60초마다 뚱뚱이 → 겁쟁이 → 낙서쟁이 → 통통이가 순서대로 예약된다.
- 현재 조작하는 블록을 바꾸지 않는다. NEXT 앞에 예약한 한 개를 넣고 안전한 다음 생성 때 꺼낸다. 일반 블록의 순서와 난수 흐름을 유지한다.
- 타이머는 실제 활성 경과 시간을 세며, 일시정지·다른 탭·게임 종료에서는 멈춘다. 줄 제거 및 짧은 장난 연출은 센다. 밀린 예약은 최대 한 개로 합친다.
- NEXT/보관/회전에도 종류·한 얼굴·크레용 표시를 유지한다. NEXT 확대에는 해당 친구의 설명이 나온다.
- 통통이의 튀기·구르기, 뚱뚱이의 빈칸 확장, 겁쟁이의 착지 직전 도망, 낙서쟁이의 실제 낙서 1~2칸을 기존 보드에 적용한다.
- 낙서는 선을 다 그린 순간 실제 칸이 된다. 장난 완료 후 기존 줄 제거·점수·콤보·꽃·아이템 처리로 이어진다.
- 짧은 장난 동작 중에는 중복 조작과 지반/아이템의 동시 보드 변경을 막는다. 일시정지는 가능하다. 재개 후 남은 동작부터 계속한다.
- 원래 몸에 붙은 아이템은 유지하며, 뚱뚱이의 추가 칸에 아이템을 복제하지 않는다.
- 튜토리얼·일반 블록 조작·165ms 짧은 스와이프 기준·기록 저장 키·기존 오디오/꽃 모듈은 유지한다. 조작 보호 구간 5개는 기준 main과 모두 동일하다.
- 기존 실험실 링크도 같은 공용 동작/그리기 코드를 사용한다. 본게임은 실험실 화면에 의존하지 않는다.

### 기존 검사 불일치

1. CONTROL `actions`의 저장된 기준 해시가 기존 main과 불일치한다. 이번 작업 전후 실제 코드 해시는 동일하다. 다른 네 보호 구간도 변경되지 않았다.
2. 오디오 검사 한 개가 좌우 이동은 무음이어야 한다고 기대하지만 현재 AUDIO6은 이동음을 낸다. 기준 main의 앱으로도 같은 `2 !== 0` 결과를 재현했다. 기존 소리 동작을 바꾸지 않았다.

전체 RC 검사를 모두 통과했다거나 출시 준비가 완료됐다는 의미는 아니다. 이번 요청의 코드·브라우저 검증과 GitHub 업로드·공개 배포 확인은 각각 구분한다.

## 휴대폰에서 확인하기

1. 본게임 새 링크에서 새 판을 시작한다. 처음 접속이면 기존 튜토리얼을 마친다.
2. 첫 통통이를 쏙! 내리면 튀는 장난 뒤 고정돼야 한다.
3. 1분, 2분, 3분 경계 뒤 다음 블록에 각각 뚱뚱이·겁쟁이·낙서쟁이가 나와야 한다. 그 순간 줄 제거 중이면 처리가 끝난 뒤 나온다.
4. HOLD에 넣고 다음 블록을 내린 뒤 다시 꺼내도 같은 종류여야 한다.
5. 잠깐 쉬었다 계속해도 장난이 중복되지 않아야 한다. 긴 누름 후 옆으로 밀면 회전하지 않고, 새 짧은 좌우 스와이프는 회전해야 한다.

실행 검사: `tests/toy-main.test.cjs`, `tests/toy-main-browser.cjs --realtime`.
새 폰트는 기존 Gaegu의 동일한 OFL 부분집합이며, 기존 글꼴 파일을 교체하지 않는다. 라이선스: `dist/qa/toy-assets/Gaegu-OFL.txt`.
