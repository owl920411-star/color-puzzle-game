# GLASSFALL — ADAPTIVE DESERT DIRECTOR V1

상태: 사용자 아이디어에 대한 기획 초안. 아직 구현·게임 적용·효과 검증하지 않음.
이번 작업은 기획 문서 작성과 현행 코드 읽기만 수행하며 DEV/MAIN을 수정하지 않는다.

## 1. 제안의 출발점

전 세계 테트리스 평균이나 나이별 실력을 추정하지 않는다. 현재 플레이어가 주어진 압박을 얼마나 안정적으로 처리하는지 관찰하고, 감당할 수 있는 범위에서 도전과 회복을 조절한다.

빠른 점수 상승, 빠른 연속 제거, 빠른 즉시하강은 후보 신호다. 어떤 신호도 단독으로 고수 판정이나 난이도 상승을 발생시키지 않는다. 나이·성별·지능은 수집하거나 추론할 필요가 없다.

목표는 모든 사람을 7분에 게임오버시키는 것이 아니다. 초보의 첫 7분 전후 학습·회복 기회를 늘리면서 성장에 따른 더 긴 생존을 허용한다. 7분은 희망하는 설계 목표이지, 검증된 평균 또는 생존 보장이 아니다.

## 3. 두 가지 판단을 분리

**실력 추정:** 비슷한 난이도에서 반복적으로 보인 처리 속도, 배치 결과, 회복 능력. 여러 판에 걸쳐 천천히 갱신한다.

**현재 부담:** 현재 보드 높이와 상승 추세, 막힌 빈칸의 증가, 방해 처리 여유, 최근 안정성. 현재 판 안에서 갱신한다.

고수도 일시적으로 위험할 수 있고, 느리게 하더라도 좋은 배치를 할 수 있다. ‘빠름=고수’, ‘높은 판=초보’, ‘한 번 사망=실력 하락’으로 처리하지 않는다.

## 4. 관찰 데이터

블록 출현, 최초 유효 입력, 최종 고정, 하드드롭 성공, HOLD, 정상 줄 제거 확정, 아이템 처리, 지반 상승, 일시정지/재개, 게임오버를 구분한다.

핵심 지표 후보:

| 지표 | 해석 원칙 |
|---|---|
| 유효 조작시간당 고정 블록 수 | 실제 처리량. 버튼을 누른 횟수와 구분 |
| 출현부터 하드드롭 확정까지 걸린 시간 | 배치 결과와 결합하고 강제 낙하·남은 조작시간을 고려 |
| 일정 블록 수당 자연 제거 줄 수 | 점수 배수·연출 속도와 분리. 단기 준비 구간은 오판하지 않음 |
| 사람 배치로 새로 생긴 막힌 빈칸 | 아이템·지반으로 생긴 변화와 분리 |
| 보드 높이의 추세와 위험 회복 | 순간 높이 하나로 판정하지 않음 |
| 연속 줄 제거·다중 줄 제거의 지속성 | 콤보 전략을 쓰지 않는 사람도 불이익 없이 평가 |
| 당시 낙하 주기·지반 주기·활성 저주 | 서로 다른 난이도의 성과를 직접 비교하지 않기 위한 문맥 |

효과로 제거된 블록을 플레이어의 빠른 입력 능력으로 계산하지 않는다. 고레벨의 점수 배수로 생긴 증가를 실력 급상승으로 해석하지 않는다. 같은 버튼 연타, 무효 입력, 일시정지, 메뉴, 고정 연출 구간, 심한 프레임 정체는 속도 지표에서 제외하거나 신뢰도를 낮춘다.

## 5. 핵심 기획 규칙 12개

1. **속도와 배치 품질의 이중 조건.** 속도만 높고 구멍이 늘면 상승시키지 않는다. 충분한 처리량과 안정적 결과를 함께 확인한다.
2. **한 번의 성공 대신 여러 배치 묶음.** 최근 20~30개 배치와 60~90초 추세를 관찰하는 것을 첫 후보로 둔다. 수치는 검증 전이다. 새 배치가 충분히 늘어난 뒤 재평가해 겹치는 창을 독립 증거처럼 세지 않는다.
3. **실력과 현재 부담의 분리.** 장기 프로필은 느리게, 현재 판의 회복 조절은 별도로 갱신한다. 처음에는 여유 있게 시작하며 관찰이 부족하면 어려워지는 변경을 보류한다.
4. **상승은 천천히, 위험 시 우선 동결.** 여러 조건이 지속될 때만 한 단계 상승한다. 어려워진 직후 또 올라가지 않도록 대기시간과 총 조절 폭을 둔다.
5. **배치가 끝난 안전한 시점에만 적용.** 현재 떨어지는 블록, 공개된 NEXT, 이미 시작된 아이템 타이머, 이미 예고한 지반 상승 시각을 불리하게 바꾸지 않는다.
6. **V1은 지반 주기 하나부터.** 기존 레벨 진행·아이템 해금은 유지하고 지반 주기만 제한적으로 조절한다. 효과를 확인하기 전에 낙하·저주·구멍 패턴을 동시에 변경하지 않는다.
7. **긴장과 회복의 교대.** 높은 실력을 보인다고 계속 끝없이 압박을 올리지 않는다. 회복 뒤 잠깐 안정 구간을 두고 현재 선택한 도전 범위의 상한을 지킨다.
8. **기존 아이템 Director와 통합.** 여러 시스템이 각자 도와주거나 벌주지 않도록 감독을 한곳에서 결정한다. 아이템 배치 결과를 감지하고 기존 정화 보상·효과를 조용히 깎지 않는다.
9. **플레이어의 선택권.** 적응형 사용을 알리고 편안하게/균형/도전 성향과 조절 끄기·프로필 초기화를 고려한다. 나이로 추정하거나 무조건 고난도를 강제하지 않는다.
10. **개인 기록의 문맥 저장.** 실제 난이도, 보조량, 버전을 점수와 함께 기록한다. 적응형과 고정 규칙 랭킹은 분리하는 것을 후속안으로 둔다. 임의의 보정 배수로 공정한 순위를 보장하지 않는다.
11. **무한 완화·고의 부진의 악용 방지.** 멈춤이나 무효 연타는 실력 판단에 넣지 않는다. 위험 상태가 계속된다고 지반을 끝없이 늦추지 않는다. 회복 주기별 지원 상한을 두며 완전한 악용 방지를 주장하지 않는다.
12. **관찰 전용 검증부터.** 먼저 실제 난이도는 그대로 두고 판정과 이유만 DEV LAB에 표시한다. 빠르지만 무너지는 플레이, 느리지만 안정적인 플레이, 준비 후 4줄 제거, 아이템 회복, 일시정지, DEV 강제 상태, 성능 저하를 따로 확인한다.

## 6. 제어 예시 — 수치는 모두 검증 전 초안

기존 지반 주기 38초인 구간의 예:

- 처리 빠름 + 자연 줄 제거 지속 + 높이/구멍 안정 + 충분한 관찰: 이후 지반 주기를 점차 33초 부근까지 짧게 검토.
- 처리 적정 + 위험이 누적되지 않음: 38초 유지.
- 유효하게 플레이 중인데 위험이 지속 증가: 이후 주기를 점차 50초 부근까지 길게 검토.
- 빠른 연타 + 구멍/높이 증가: 고수 판정 금지, 상승 보류.
- 데이터 부족/메뉴/성능 불안정: 신규 상승 보류, 실력 프로필 갱신하지 않음.

초기 제한 후보: 현재 단계 기본 주기의 0.85~1.35배, 한 조정 약 5%, 조정 뒤 최소 30초 재관찰. 즉시 38→33초로 바꾸는 뜻이 아니다. 이미 예고된 상승은 건드리지 않고 다음 전체 주기부터 적용한다. 고정 규칙 하한·안전 규칙과 충돌하면 안전 제약이 우선한다.

사망 주원인이 지반이 아닌 기본 배치 시간 부족이라면 이 제어 하나로 해결되지 않을 수 있다. 그 경우 다음 단계에서 판 시작 시의 낙하 프리셋을 개인화하되, 터치 민감도·회전 규칙·즉시하강 반응 자체는 난이도 조절 대상으로 삼지 않는다.

## 7. 저장과 실행 구조

초기 모델은 복잡한 AI나 외부 서버 호출 대신 로컬 규칙과 이동 통계로 시작한다. 현재 브라우저에 플레이 요약을 보관하고 새 판의 초기값 참고로 쓰는 구조를 제안한다. 같은 기기를 여러 사람이 쓰면 기록이 섞일 수 있으므로 임시 플레이/프로필 초기화 같은 구분이 필요하다. 서버 없는 V1은 다른 기기로 개인을 자동 식별·동기화하는 구조가 아니다.

배치/줄 제거 같은 사건이 끝났을 때 지표를 갱신하고 일정 주기마다 판정한다. 매 프레임 전체 탐색이나 외부 AI 호출을 하지 않도록 설계한다. 실제 모바일 성능은 별도로 측정한다.

## 8. 계획 보존과 검증 한계

- [ ] 배치 사건과 시스템 변경 원인별 계측
- [ ] 점수/효과와 분리된 속도·안정성 지표
- [ ] 개인 프로필과 현재 부담 분리
- [ ] 관찰 전용 판정 및 이유 표시
- [ ] 제한형 지반 주기 조절
- [ ] 사용자 선택 및 설정 초기화
- [ ] 기록 모드·규칙 버전 분리
- [ ] 과민 변화·고의 부진·무한 완화 테스트
- [ ] 휴대폰 체감·7분 목표 검증
- [ ] 필요할 때 후속 낙하 프리셋/아이템 감독 통합

이번 문서는 새 기획이다. 코드 구현, 적응형 동작 테스트, 재미 향상, 초보 생존시간 향상은 아직 확인하지 않았다. 과거 보드 회귀 검사나 근사 생존 시뮬레이터를 이 적응형 시스템의 실력 감지 검증으로 재사용하지 않는다. 인간 평균을 찾는 대규모 작업은 전제가 아니지만, 실제 오판과 체감을 확인하는 반복 테스트는 필요하다.
