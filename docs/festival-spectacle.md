# 퍼즐 축제 연출 강화

퍼즐 규칙과 4번째 스테이지의 45초·25개 목표를 유지하며 축제 연출을 강화했습니다. 농장 관리 기능은 추가하지 않았습니다.

- 시작 시 FESTIVAL TIME 환영 배너, 양쪽 불꽃과 색종이 발사
- 밤하늘에서 주기적으로 터지는 서로 다른 색의 불꽃놀이
- 배경에서 천천히 움직이는 세 가지 무대 조명
- 밝기가 부드럽게 변하는 상단 전구
- 전구와 분홍·보라·청록빛으로 장식한 퍼즐 테두리
- 축제 전용 시작 팝업과 LET’S PARTY 이름표
- 매 조합마다 삼중 빛고리·큰 별·색종이 폭발
- 3콤보 이상 또는 PERFECT 성공 시 추가 불꽃
- 5콤보 이상에서 색종이와 지연 폭발, 8콤보 이상에서 양옆 연속 불꽃
- 피버 진입 시 MEGA FEVER! 배너, 다섯 차례 추가 불꽃과 대량 색종이
- 클리어 화면 위로 이어지는 대형 불꽃과 색종이 피날레
- 실패·재시작·다음 스테이지 이동 시 연출 정리

큰 불꽃은 주로 헤더에, 색종이는 화면 양옆에 배치합니다. 장식은 터치 입력을 받지 않습니다. 게임의 난수와 별도의 시각효과 난수를 사용해 타일 생성·점수·시간 계산에 영향을 주지 않습니다.

모바일 부하를 제한하기 위해 캔버스 입자는 최대 520개, 대기 중인 연쇄 효과는 최대 24개, 갱신은 약 30fps, 해상도 배율은 최대 1.5로 제한했습니다. 메뉴·화면 숨김 시 애니메이션을 정지합니다. 동작 줄이기 설정에서는 정적인 축제 장식만 표시합니다.

검증: 기존 133개 회귀 검사 및 새 축제 연출 17개 검사 통과. 시작·피버·클리어·일시정지·재개·스테이지 전환·입자 및 연쇄 효과 상한·매 조합 폭발·클리어 화면 레이어·난수 분리·동작 줄이기를 확인했으며 320px/390px 화면에서 환영 배너가 게임 현황을 가리지 않는지 확인했습니다.

현재 버전: `festival-mega-4`. 입자를 크게 하고 가산 합성으로 빛을 강화했으며, 불꽃 간격을 0.7초로 줄였습니다. 네온 테두리와 무대 조명도 강화했습니다. 전체 화면 섬광이나 퍼즐판 흔들림 없이 폭발감을 표현합니다. 총 150개 검사 통과.
