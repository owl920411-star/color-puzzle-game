# GLASSFALL · 글래스폴

유리·모래·물·젤리 중 소재를 골라 배치와 연결을 만드는 모바일 낙하 퍼즐입니다.

## 실행과 검증

- 정적 출력: `dist/`. 루트 `index.html`은 `dist/`로 연결됩니다.
- 외부 런타임 의존성이나 빌드 과정은 없습니다.
- 실행: `python -m http.server 8080 --directory dist`
- 검증: `node --test tests/*.test.cjs`, `node --check dist/app.js`
- 기존 Sites 프로젝트와 GitHub 저장소에 같은 소스를 반영합니다.

## 소재별 규칙

메뉴에서 소재를 선택한 다음 3분·무한·오늘 모드로 시작합니다. 이번 버전은 소재별 독립 플레이이며, 한 판에서 여러 소재를 혼합하는 방식은 아닙니다.

| 소재 | 착지 후 움직임 | 제거 조건 |
|---|---|---|
| 유리 | 모양을 유지, 파쇄 후 열별 낙하 | 가로줄 완성 + 맞닿은 흰 균열 전파 |
| 모래 | 각 칸이 아래 또는 대각선으로 흩어짐 | 상하좌우로 연결된 같은 색이 왼쪽·오른쪽 벽 모두에 닿음 |
| 물 | 아래·대각선·옆의 열린 통로를 통해 낮은 빈칸으로 흐름 | 같은 색 10칸 이상이 상하좌우로 연결 |
| 젤리 | 같은 색의 연결 덩어리가 형태를 유지하며 낙하 | 같은 색 8칸 이상이 상하좌우로 연결 |

새 소재는 네 색을 사용하며 새 조각의 네 칸은 같은 색입니다. 실제 유체 해석 대신 10×20 격자 규칙을 사용합니다. 모래의 미세 낱알은 표현 효과이며 판정 단위는 한 칸입니다. 물은 빈 통로만 통과하고 젤리는 한 덩어리 전체가 이동 가능할 때만 내려갑니다.

착지 → 흐름 안정 → 연결 제거 → 다시 흐름 순서로 처리합니다. 흐름이 진행되는 동안 다음 조각을 조작할 수 없고, 일시정지하면 움직임도 멈춥니다. 시간 만료 시 진행 중인 흐름과 연쇄까지 정산합니다. 새 소재는 완성 가로줄을 자동 제거하지 않으며 연결 묶음 수에 따라 레벨이 올라갑니다. 새 소재 점수는 `(제거한 칸 × 20 + 제거 묶음 × 100) × 연쇄`이고, 유리의 기존 점수는 유지합니다. 유리의 2연쇄 상한은 새 소재의 색 연결 규칙에 적용하지 않습니다.

## 유리 규칙과 공통 조작

10열 × 20행, 7종 조각. 완성된 가로줄에서 양쪽 셀의 흰 균열 끝이 맞닿은 유리로 파쇄가 전파됩니다. 색은 무관합니다. 제거 대상을 먼저 확정한 뒤 열별로 유리를 압축하고 새 완성줄을 판정합니다. 이 규칙의 파쇄 파동은 한 배치당 최대 2연쇄입니다.

- 게임판 또는 하단 패드를 짧게 탭: 손을 뗄 때 시계 방향 회전.
- 좌우 스와이프: 한 칸 또는 여러 칸 이동.
- 아래로 빠르게 쓸고 떼기: 즉시 낙하. 느리게 아래로 밀기: 천천히 내리기.
- 별도 보관 버튼, 접이식 좌우/낙하 보조 버튼.
- 키보드: ← → 이동, ↑/X 회전, ↓ 하강, Space 즉시 낙하, C 보관, P/Escape 일시정지.

탭은 300ms 이내, 접촉 전체 최대 이동 10 CSS px 이내입니다. 위 스와이프는 회전하지 않습니다. 접촉 하나는 조각 하나만 소유하며 취소·일시정지·조각 교체 후 남은 입력을 다음 조각에 적용하지 않습니다. 650ms 잠금 유예, 창 이탈 시 자동 일시정지를 유지합니다.

## 완성도 업데이트: 목표·숙련도·난이도

각 판에 조각 배치, 제거량, 점수의 목표 3개가 주어집니다. 달성 시 15/30/45 XP, 모두 달성하면 추가 25 XP를 받습니다. XP는 판이 정상 종료될 때 한 번만 소재별로 저장됩니다. 중도 재시작·메뉴 이탈·연습에서는 지급하지 않습니다. 효과와 목표는 점수 판정을 바꾸지 않습니다.

| 난이도 | 조각 배치 | 제거량 | 점수 | 낙하 / 시작 판 |
|---|---:|---:|---:|---|
| 여유 | 4개 | 8칸 | 300점 | 낙하 간격 1.4배, 잠금 유예 850ms, 빈 판 |
| 기본 | 6개 | 16칸 | 600점 | 기존 속도와 650ms 잠금 유예, 빈 판 |
| 도전 | 10개 | 24칸 | 1,000점 | 낙하 간격 0.76배, 바닥 3행 범위에 초기 배치 |

도전 바닥은 같은 시드·소재·난이도에서 동일합니다. 새 난이도 기록은 `calm:` / `challenge:` 접두사로 분리하며 기본 난이도의 기존 기록 키는 유지합니다. 기록과 동일 판 비교는 난이도까지 일치해야 합니다. 초기 바닥은 점수를 주지 않으며 실제로 제거했을 때만 점수를 받습니다.

소재 숙련도는 누적 XP 0/100/260/500/850/1300에서 Lv.1~6이 됩니다. Lv.3 공명 테두리, Lv.5 오로라 테두리는 자동 적용되는 외형 보상입니다. 숙련도가 규칙·색 확률·물리나 점수 배율에 영향을 주지 않습니다. 진척은 기기에 저장됩니다.

연결에 가까운 묶음은 점선과 짧은 안내로 표시합니다. 유리는 6칸 이상 채운 행, 물은 6칸 이상 연결, 젤리는 4칸 이상 연결, 모래는 4열 이상 이어진 묶음을 대상으로 합니다. 상하좌우 실제 연결만 계산하며 착지 이후 흐름을 미리 계산해 정답을 제시하는 기능은 아닙니다.

## 손맛과 효과 설정

소재별 음색·짧은 음높이 변화, 착지 파문, 제거 파문과 획득 점수 표시를 추가했습니다. 입자는 풍부 모드 최대 200개, 간결 모드 최대 45개, 동시 점수 효과는 최대 6개로 제한합니다. 게임 방법에서 효과 풍부/간결을 고를 수 있고 기기의 동작 줄이기 설정은 우선 적용됩니다. 효과 설정에 따라 흐름·파쇄 대기시간이나 점수는 변하지 않습니다. 진동은 지원 브라우저에서 사용자가 켤 때만 작동합니다. 소리는 기존 버튼으로 켤 수 있습니다.

## 플레이 모드

- 3분 도전: 180초 점수 도전. 시간 종료 시 진행 중인 파쇄를 정산합니다.
- 무한 모드: 줄 제거에 따라 레벨과 낙하 속도가 증가합니다.
- 오늘의 도전: 한국 날짜 기준 고정된 조각·균열 순서, 3분 제한.
- 조작 연습: 준비된 배치로 이동·낙하·균열 원리를 연습합니다. 기록에 포함하지 않습니다.

사용자 요청으로 균열 연구실의 메뉴, 고정 퍼즐 9개, 별 해금 화면, 전용 코드와 테스트를 제거했습니다. 기존 기기 데이터의 이전 연구 기록은 읽거나 표시하지 않으며, 점수·배지 등 다른 기록은 보존합니다. 기본 게임의 균열 파쇄 규칙은 유지합니다.

## 같은 판 재도전과 개선 기록

결과 화면에서 동일 소재·동일 모드·동일 시드의 직전 완료 판과 점수, 제거한 줄, 추가 파쇄, 조각당 제거 유리를 비교합니다. 제거 효율은 제거한 유리 수 ÷ 배치한 조각 수이며 조각을 쓰지 않았다면 0입니다. 이전 버전에 없던 지표는 비교값을 `—`로 표시합니다.

같은 판의 최고 점수와 도전 횟수를 저장하고, 재도전 중에는 최고 점수 갱신까지 남은 점수를 표시합니다. 낮은 점수로 다시 끝내도 최고 기록은 유지합니다. 메뉴의 ‘직전 판 기록에 재도전’으로 재접속 후에도 같은 조각 순서를 불러올 수 있습니다. 오늘의 도전 메뉴에서는 오늘 날짜의 기록만 불러옵니다. 중도에 그만둔 판은 완료 기록에 포함하지 않습니다.

`localStorage`의 기존 `glassfall-v1` 안에 최근 12개 소재·난이도·모드·시드 조합의 상세 비교 기록을 저장합니다. 소재 선택을 저장하고, 신규 소재의 기록 키는 `sand:`, `water:`, `jelly:`로 구분합니다. 기존 소재 표시가 없는 기록은 유리 기록으로 취급합니다. 기존 최고 점수·유리 배지·모드별 최고 연쇄는 유지합니다. 계정 동기화나 온라인 순위표는 없으며 브라우저 데이터 삭제 시 기록이 사라집니다.

## 모바일 화면과 검증 범위

실제 안내·조작 영역의 높이에 맞춰 게임판 높이를 계산합니다. 화면 회전과 주소창 높이 변경에도 다시 계산하고 확대 중에는 게임판을 축소하지 않습니다. 보드는 최소 240px로 유지하여 짧은 화면이나 큰 글씨 설정에서는 페이지 스크롤이 필요할 수 있습니다. 모바일 메뉴와 결과 창은 화면 폭을 사용하고 내부 스크롤을 지원합니다.

자동 검증은 게임 엔진, 실제 입력 핸들러, 소재별 제거 조건과 연쇄, 셀 수 보존·흐름 종료·결정성, 일시정지·시간 만료 정산, 소재·난이도별 비교 기록, XP 중복 지급 방지, 숙련도 해금·재접속·이전 저장 호환성을 확인합니다. 캔버스 렌더러로 소재 그래픽도 확인합니다. 실제 Android 브라우저의 화면·터치 체감·성능을 검증한 것은 아닙니다.

## 모바일 집중 화면

모바일 기본 화면은 점수·시간·일시정지, 큰 게임판과 작은 다음 조각·보관으로 구성합니다. 큰 브랜드 헤더, 목표 패널, 상세 기록, 안내문, 하단 조작 패드는 플레이 화면에서 숨깁니다. 게임판 자체의 탭 회전·스와이프 조작을 사용합니다. 모바일에는 다음 조각 한 개를 표시하며 데스크톱은 기존 세 개를 표시합니다.

일시정지 메뉴의 ‘목표와 기록’을 펼치면 목표·레벨·연쇄·제거량·같은 판 최고 점수와 소재 규칙을 확인할 수 있습니다. 소리, 설정·도움말, 조작 패드 켜기/끄기도 여기서 접근합니다. 패드를 켜면 기존 보조 버튼도 펼칠 수 있으며 선택은 기기에 저장됩니다. 목표 판정·XP·기록 저장은 계속 유지합니다.

게임판의 이전 640px 높이 상한을 없애고 실제 남은 화면 높이와 폭으로 맞춥니다. 모바일 메뉴는 화면 전체에 가까운 대화상자로 표시합니다. 화면이 매우 짧거나 글씨가 커진 경우 스크롤을 허용합니다. 실제 기기 스크린샷에 근거해 조정했으며 수정 후 실제 Android 브라우저 화면을 확인한 것은 아닙니다.
