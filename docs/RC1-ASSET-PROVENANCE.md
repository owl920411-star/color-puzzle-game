# RC1 presentation assets

- Official baby + chick: existing `bloom-home-hero.webp`, retained without redesign.
- Hand-drawn logo: existing `bloom-home-logo.webp`, retained.
- New standalone chick: `bloom-chick.webp` (320px, 36,472 bytes, alpha).
  Generated for this project with the built-in image generator using the official
  hero as a reference. No external stock artwork or music was downloaded.
  Only resizing/encoding was applied to the generated PNG.

Generation direction: precise object edit; isolate a complete yellow chick in
the official reference's wax-crayon picture-book style, facing the viewer with
small lifted wings, pink cheeks, orange beak and feet, uneven brown outlines,
grainy pigment. Transparent background. No baby, hands, text, extra decorations,
gloss, 3D or smooth vector treatment. Preserve the reference chick identity.

All combo tiers reuse these decoded images and a fixed small set of drawn marks.
Audio is original procedural composition/synthesis in `bloom-audio.js`; see
`CRAYON-BLOOM-RC-AUDIO.md`. No commercial melody or recording was used.
