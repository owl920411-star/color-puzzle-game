# COLOR LINK — 핵심 재미 실험 01

기존 게임을 두 판 이상 이어 하지 않게 되는 이유로 사용자는 시간 압박보다 ‘규칙을 이해한 순간 이게 끝이라고 느끼는 단순함’을 지적했습니다. 이 실험은 합성 결과가 남도록 바꾸어 놓는 방향과 조합 순서가 다음 선택에 영향을 주는지 확인합니다. 재미가 검증됐다는 뜻은 아닙니다.

## 실행

`experiments/color-link.html`을 다운로드하여 브라우저로 엽니다. HTML 하나에 화면·규칙·소리를 포함하며 외부 이미지, 라이브러리, 인터넷 연결이 필요하지 않습니다. 일반 정적 호스팅에서도 같은 경로로 제공할 수 있습니다. 기존 `index.html`, `game.js`, 기존 저장 데이터는 수정하지 않습니다.

## 규칙

- 4×4 고정 배치, 시간제한 없음.
- 상하좌우의 서로 다른 기본색을 합칩니다. 빨강+파랑=보라, 빨강+노랑=주황, 파랑+노랑=초록.
- 결과물은 도착 칸에 남고 출발 칸은 비어 있습니다. 타일 보충·중력·임의 이동은 없습니다.
- 같은 결과색 3개 이상이 상하좌우로 연결되면 제거합니다. 꺾인 연결도 인정합니다.
- 결과물은 다른 타일과 합칠 수 없습니다. 잘못 놓으면 한 수 되돌리기나 처음 배치로 돌아가기를 사용합니다.
- 스와이프, 두 번 탭, 키보드 Enter/Space로 선택 및 합성할 수 있습니다. 화살표로 초점을 이동합니다.
- 동작 감소 설정을 따르고, 소리는 기본 꺼짐입니다. 색과 기호를 함께 표시합니다.
- 개인 최소 조합 횟수만 `color-link-experiment-v1`에 저장합니다. 저장 불가 환경에서도 게임은 동작합니다.

## 네 가지 판

1. 방향: 같은 두 타일도 반대로 밀면 결과가 달라집니다.
2. 배치: 세 번의 합성으로 보라 3개를 연결합니다.
3. 두 색: 보라 3개와 초록 3개를 각각 완성합니다. 처리 순서는 자유입니다.
4. 연결: 두 무리 사이에 보라 하나를 놓아 5개를 한 번에 연결합니다.

무작위 보충을 제외했으므로 실패 후 같은 조건에서 다른 방향을 비교할 수 있습니다. 처음 실험에서 전략의 폭은 제한적입니다. 이 네 판의 목적은 방향 선택과 준비 후 연결의 감각을 확인하는 것이며, 장기 콘텐츠나 인기 가능성을 입증하는 것이 아닙니다.

## 검증

`node tests/color-link.cjs`

10개 규칙·해결 가능성 검사와 두 스크립트의 문법 검사가 통과했습니다. 네 판의 해결 경로, 같은 쌍의 반대 방향 결과, 결과물 유지/무보충, 꺾인 연결, 5개 연결, 행 경계/대각선/빈칸/결과물/같은 색/잘못된 좌표 거부, 세 색 조합, 복수 목표 판정을 검사합니다.

브라우저 화면·터치 검사는 미완료입니다. 이 세션에서 로컬 브라우저 다운로드가 시간 초과했고, 클라우드 브라우저는 로컬 파일 프로토콜을 보안 정책으로 차단했습니다. 해당 제한을 우회하지 않았습니다. 실제 Android 성능·레이아웃·오디오·포인터 이벤트·저장 유지 여부를 검증한 것으로 해석하면 안 됩니다.

수동 확인: 320px/360px/412px에서 가로 넘침, 첫 판 반대 방향 후 되돌리기, 빠른 연속 입력, 합성 애니메이션 중 처음 배치/다른 판 이동, 4판 완료 후 재시작, 소리 전환, 동작 감소, 저장 차단 상태를 확인합니다.

## 사용자에게 확인할 것

- 합치기 전에 도착 위치를 생각했나요?
- 잘못 놓은 뒤 다른 방향으로 다시 해보고 싶었나요?
- 세 개/다섯 개가 연결될 때 직접 준비해서 터뜨렸다는 느낌이 있나요?

위 반응이 없다면 판을 더 만들기 전에 핵심 규칙을 다시 검토합니다. 기존 게임으로 병합하거나 서비스에 배포하지 않은 별도 실험입니다.
