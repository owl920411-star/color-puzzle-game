# GLASSFALL · 글래스폴

유리를 배치해 가로줄을 완성하고 이어진 균열을 파쇄하는 모바일 낙하 퍼즐입니다.

## 실행과 검증

- 정적 출력: `dist/`. 루트 `index.html`은 `dist/`로 연결됩니다.
- 외부 런타임 의존성이나 빌드 과정은 없습니다.
- 실행: `python -m http.server 8080 --directory dist`
- 검증: `node --test tests/*.test.cjs`, `node --check dist/app.js`
- 기존 Sites 프로젝트와 GitHub 저장소에 같은 소스를 반영합니다.

## 규칙과 조작

10열 × 20행, 7종 조각. 완성된 가로줄에서 양쪽 셀의 흰 균열 끝이 맞닿은 유리로 파쇄가 전파됩니다. 색은 무관합니다. 제거 대상을 먼저 확정한 뒤 열별로 유리를 압축하고 새 완성줄을 판정합니다. 이 규칙의 파쇄 파동은 한 배치당 최대 2연쇄입니다.

- 게임판 또는 하단 패드를 짧게 탭: 손을 뗄 때 시계 방향 회전.
- 좌우 스와이프: 한 칸 또는 여러 칸 이동.
- 아래로 빠르게 쓸고 떼기: 즉시 낙하. 느리게 아래로 밀기: 천천히 내리기.
- 별도 보관 버튼, 접이식 좌우/낙하 보조 버튼.
- 키보드: ← → 이동, ↑/X 회전, ↓ 하강, Space 즉시 낙하, C 보관, P/Escape 일시정지.

탭은 300ms 이내, 접촉 전체 최대 이동 10 CSS px 이내입니다. 위 스와이프는 회전하지 않습니다. 접촉 하나는 조각 하나만 소유하며 취소·일시정지·조각 교체 후 남은 입력을 다음 조각에 적용하지 않습니다. 650ms 잠금 유예, 창 이탈 시 자동 일시정지를 유지합니다.

## 플레이 모드

- 3분 도전: 180초 점수 도전. 시간 종료 시 진행 중인 파쇄를 정산합니다.
- 무한 모드: 줄 제거에 따라 레벨과 낙하 속도가 증가합니다.
- 오늘의 도전: 한국 날짜 기준 고정된 조각·균열 순서, 3분 제한.
- 조작 연습: 준비된 배치로 이동·낙하·균열 원리를 연습합니다. 기록에 포함하지 않습니다.

사용자 요청으로 균열 연구실의 메뉴, 고정 퍼즐 9개, 별 해금 화면, 전용 코드와 테스트를 제거했습니다. 기존 기기 데이터의 이전 연구 기록은 읽거나 표시하지 않으며, 점수·배지 등 다른 기록은 보존합니다. 기본 게임의 균열 파쇄 규칙은 유지합니다.

## 같은 판 재도전과 개선 기록

결과 화면에서 동일 모드·동일 시드의 직전 완료 판과 점수, 제거한 줄, 추가 파쇄, 조각당 제거 유리를 비교합니다. 제거 효율은 제거한 유리 수 ÷ 배치한 조각 수이며 조각을 쓰지 않았다면 0입니다. 이전 버전에 없던 지표는 비교값을 `—`로 표시합니다.

같은 판의 최고 점수와 도전 횟수를 저장하고, 재도전 중에는 최고 점수 갱신까지 남은 점수를 표시합니다. 낮은 점수로 다시 끝내도 최고 기록은 유지합니다. 메뉴의 ‘직전 판 기록에 재도전’으로 재접속 후에도 같은 조각 순서를 불러올 수 있습니다. 오늘의 도전 메뉴에서는 오늘 날짜의 기록만 불러옵니다. 중도에 그만둔 판은 완료 기록에 포함하지 않습니다.

`localStorage`의 기존 `glassfall-v1` 안에 최근 12개 모드·시드 조합의 상세 비교 기록을 저장합니다. 기존 최고 점수·배지·모드별 최고 연쇄는 유지합니다. 계정 동기화나 온라인 순위표는 없으며 브라우저 데이터 삭제 시 기록이 사라집니다.

## 모바일 화면과 검증 범위

실제 안내·조작 영역의 높이에 맞춰 게임판 높이를 계산합니다. 화면 회전과 주소창 높이 변경에도 다시 계산하고 확대 중에는 게임판을 축소하지 않습니다. 보드는 최소 240px로 유지하여 짧은 화면이나 큰 글씨 설정에서는 페이지 스크롤이 필요할 수 있습니다. 모바일 메뉴와 결과 창은 화면 폭을 사용하고 내부 스크롤을 지원합니다.

자동 검증은 게임 엔진, 실제 입력 핸들러, 비교 기록·최고 기록 보존·재접속·이전 저장 호환성을 확인합니다. 실제 Android 브라우저의 화면·터치 체감·성능을 검증한 것은 아닙니다.
