# 장난블록 학습 후 예고 숨김

- 사용자가 선택한 정책: 실제 한 판의 플레이 시간이 240초 이상이고, 네 종류를 모두 만난 경우 장난 행동 예고를 숨기고 저장한다.
- toyGuidanceHidden=true를 기존 저장 데이터에 추가. 재시작·재접속·기본 조작 튜토리얼 다시 보기 후에도 숨김 유지.
- 점선 최종 칸, 방향, 확장 ＋, 잉크 빗금 및 첫 만남 안내 숨김. 기본 착지 그림자는 유지.
- 네 종류를 아직 못 만났으면 4분 후에도 예고 유지. 다음 판의 미학습 친구 우선 순서 유지.
- 일시정지·브라우저 숨김·게임오버 시간 제외는 기존 active clock 유지. 블록 행동·대기열·CONTROL23·오디오 수정 없음.
- 검증: 새 5/5, 기존 예고 339/339, 장난블록 통합 149/149 통과. 새 검사는 조건 경계, 조건 결합, 1회 저장, 재시작·재접속·튜토리얼, 기존 설정 보존을 확인했다.
- 사람의 재미와 휴대폰 체감·화면 검증은 자동 검사의 완료 항목이 아니다.
