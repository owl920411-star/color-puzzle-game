# 장난블록 예측·첫 만남 개선
기준: main 93b837ab16d4d3f8fde9505c949fa111d65a5659 (2026-09-30)

## 실제 확인 및 변경
- 기존 본게임은 매 판 즉시 통통이, 이후 60초 간격의 고정 순서였다. 기존 착지 그림자는 행동 이전 위치였으며 행동 방향과 잉크가 행동 중 무작위로 결정됐다.
- 본게임은 일반 블록 3개 착지 또는 첫 줄 제거 뒤 첫 친구를 대기열에 추가한다. 즉시 생성하지 않으므로 이미 NEXT에 예약된 친구가 나올 때까지 일반 블록이 더 나올 수 있다. 줄 제거가 필수 조건은 아니다.
- 사용자 선택: 아직 만나지 못한 친구부터 다음 판에 소개. 전부 만나면 통통이부터 기존 순서. 첫 친구 예약을 기준으로 이후 60초 간격. 시간 제외와 예약 병합은 기존 로직 유지.
- 예고: 행동 뒤 차지할 점선 칸, 이동 방향, 확장 ＋, 잉크 빗금. 기존 능력/이동 범위/잉크 개수는 유지. 무작위 선택은 블록 생성 때 만든 seed를 사용해 위치 변화에도 같은 규칙으로 재계산한다. 예고와 실행 모두 기존 ToyLab 물리와 충돌 판정을 사용한다.
- 첫 소개는 하단 한 줄, 조작이나 낙하 정지 없음. 생성 당시 toyLearned에 저장. HOLD에서 꺼내도 현재 첫 소개 블록에 한해 안내 유지. 다음 판과 재접속은 반복 소개하지 않는다. 기존 튜토리얼 다시 보기는 학습 상태를 지우지 않는다.
- NEXT/HOLD 이름, 캐릭터 그림과 확대 도움말 유지. 착지 칸은 현재 조작 중인 장난블록에만 표시한다.
- 결과 성취 한 줄: 최고 콤보가 2 이상이면 콤보, 아니면 최대 동시 제거 줄 수. 제거가 없으면 실제 놓은 블록 수만 표현한다. 장난블록 기여를 추정하지 않는다.
- 활용: 옆 낮은 공간으로 이동, 빈칸 확장/잉크로 줄 완성. 새 능력이나 점수 규칙 없음.

## 휴대폰 확인
1. 새 미리보기에서 튜토리얼 완료 후 일반 블록을 3개 이상 놓기. 다음 차례에 통통이가 나오고 한 줄 안내가 보여야 한다.
2. 좌/우 벽과 쌓인 블록 근처에서 회전/보관 후 회수/쏙!을 사용. 행동 뒤 채워진 칸이 마지막 점선과 같아야 한다. 뚱뚱이 ＋, 낙서쟁이 빗금 확인.
3. 다시 시작 및 재접속. 만난 통통이 안내 대신 아직 못 만난 친구가 기본 착지 뒤 나와야 한다.
4. 결과의 연속/동시 제거 수가 실제 플레이와 맞고 점수·BEST·다시 하기가 명확해야 한다.
5. 짧은 터치 1칸, 꾹 연속 이동, 좌우 스와이프 회전, 위 HOLD, 아래/쏙! 즉시 하강. 안내와 점선이 조작을 방해하지 않아야 한다.
