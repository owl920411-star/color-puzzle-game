# GLASSFALL · ENDLESS 1

MAIN 기준: `45b8e72b09183f5d7aae4a8d7f7cd62f1c922a1b`. 이번 작업은 DEV 전용입니다.

## 최신 사용자 결정
유리 모드를 일반 모드로 변경. 스테이지, 오늘의 도전, 균열 표시와 주변 전파를 제거합니다. 일반과 모래 모두 시간 제한·목표 종료 없이 무한 점수제로 진행합니다. 일반 모드 회전 버튼을 다른 손가락으로 눌러도 기존 게임판 스와이프를 유지합니다.

## 실행 구조
- `dist/index.html` → `engine.js`, `sand-micro.js`, `art.js`, 새 `endless-rules.js`, 새 `endless-app.js`.
- 새 UI는 `endless.css`. 판 ID는 `board`이며 `sand-board`가 아닙니다.
- 원본 `sand-micro.js`의 UMD 물리 코어만 사용하고, `sand-board`를 요구하는 구형 컨트롤러는 실행되지 않습니다.
- `app.js`, `stages.js`, `progression.js`, `sand-route.js`는 새 진입 화면에서 로드하지 않습니다. 역사적 코드/테스트는 남아 있으므로 전체 바이트를 삭제했다고 설명하지 않습니다.
- 기존 `sand-micro.html` 링크는 새 공용 페이지의 모래 무한 플레이로 이동합니다. 이전 stage/daily 쿼리를 전달하지 않습니다.

## 일반 모드 규칙
완성한 가로줄만 지웁니다. 균열 마스크는 생성·회전·보관 모두 0. 남은 행 전체를 아래로 이동시켜 빈칸을 보존하며, 열별 압축이나 균열 전파를 호출하지 않습니다. 7종 조각/회전 벽 보정/보관/다음 블록/고스트/기존 이미지와 파편은 유지합니다.

레벨 1에서 1/2/3/4줄은 100/300/500/800점. 제거 직전 레벨을 곱합니다. 연속 제거 두 번째부터 `50 × (연속 제거 횟수 - 1) × 레벨`을 추가하며, 줄을 지우지 않은 배치에서 콤보가 끊깁니다. 10줄마다 레벨이 오르지만 판을 초기화하거나 다음 스테이지로 이동하지 않습니다. 소프트 드롭은 칸당 1점, 하드 드롭은 칸당 2점입니다.

## 모래 보존
원본 Field/Run/주머니 생성기를 수정하지 않습니다. 120×240, 주머니 576개, 착지 직후 다음 주머니, 정착 후 색 연결과 자연 연쇄를 유지합니다. 무한 모드의 기존 설정인 3색·12 모래량·중력 26을 사용합니다. 목표 전용 보석 배치는 없으며, 모래 회전 UI/탭/키 입력은 없습니다.
점수는 기존 `round(제거 알갱이/144 × 20 + 제거 묶음 × 100) × 2^min(10,chain-1)`과 기존 하드드롭 보너스를 사용합니다.

## 입력
버튼은 pointerdown 한 번에 반응하고 후속 포인터 click을 중복 처리하지 않습니다. 회전 시 게임판 pointer capture를 해제하지 않으며 회전 뒤 현재 손가락 위치를 기준으로 상대 이동을 계속합니다. 하강·보관 후 다음 조각으로 입력을 넘기되 손 떼기로 추가 회전/하강하지 않습니다. 일반 줄 제거 연출 중 이동도 다음 조각의 목표 위치에 반영합니다. pause/menu/restart/blur/visibility에서 입력 상태를 비웁니다. 모래의 느린 드래그는 마지막 손가락 좌표와 하강 누적 기준점을 분리했습니다.

## 저장
`glassfall-v1`의 기존 best/campaign/mastery/sandMicro/설정은 지우지 않습니다. 새 기록은 `endlessV1.normal`과 `endlessV1.sand`에 분리합니다. 다른 규칙의 옛 최고 점수를 신규 점수에 섞지 않습니다. 최고/최근 종료 판/종료 횟수를 저장하고 저장 실패를 표시합니다. 계정 동기화나 온라인 순위표는 없습니다.

## 검증과 한계
- Node 문법 검사, `node --test tests/endless.test.cjs`: 19개 통과.
- 로컬 Chromium 30개 검사: CDP 실제 두 손가락 이벤트로 회전 후 이동, 하강 후 다음 조각 이동, 손 떼기 중복 방지, 줄 제거 중 carry, 일시정지, 모래 입력과 양 보존, 저장 어댑터, 화면 크기 등을 확인.
- 360×640, 390×844, 412×915, 320×480, 1280×800의 게임판/조작 버튼/하단 표시가 뷰포트 안에 있음.
- 이 환경은 외부 및 localhost 브라우저 탐색이 차단되어 HTML/CSS/실제 JS를 about:blank에 주입했습니다. URL query와 localStorage는 테스트 어댑터입니다. 이미지 파일은 받지 못해 원본 art.js의 벡터 대체 렌더러를 사용했습니다.
- 따라서 실제 DEV 페이지 이동·새로고침 후 저장·원격 이미지 렌더링·휴대폰 터치감/FPS를 검증 완료라고 주장하지 않습니다. 배포 빌드는 GitHub check-runs로 별도 확인해야 합니다.
- 로컬 테스트의 engine.js/sand-micro.js/art.js는 원본 Git blob SHA와 일치하며 저장소에서도 수정하지 않습니다.
