# 축제 모드 제거 — puzzle-only-7

축제 전용 스테이지 타입·화면·폭죽·조명·개발자 진입 버튼과 이미지 로딩을 제거했습니다. 4스테이지는 일반 타입의 45초/25개 조합 목표로 유지하며 일반 스테이지의 랜덤 보정값을 사용합니다. 총 15개 스테이지와 저장 키·인덱스를 유지하므로 기존 진행 상태는 그대로 이어집니다.

일반 퍼즐의 파편·콤보·피버·나비는 유지합니다. 일반 파편 CSS는 기본 테마로 옮겼습니다. 새로운 시각 연출은 이번 변경에 추가하지 않습니다.

검증: 기존 퍼즐·나비·난이도·진행 저장 검사와 축제 리소스 요청 없음, 4스테이지 저장 복원, 파편 스타일 유지를 포함해 총 137개 검사 통과. 축제 전용 테스트는 제거하고 나비/일반 스테이지 테스트로 갱신했습니다.
