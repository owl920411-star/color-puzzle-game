## 적용 안전 검사

Windows의 기본 `core.autocrlf=true` 체크아웃에서 첫 dry run은 SAFE STOP으로 종료했다. Git 정규화 blob은 일치했으나 디스크 바이트가 CRLF여서 실제 SHA 검사는 불일치했다. 원본 소스 변경 때문이 아님을 확인했다: 최신 커밋은 ZIP만 추가했다.

별도 LF dev 체크아웃에서 두 원본 바이트를 다시 검증했다.

- dist/endless-app.js: `2d3310e38fe241ddde8215faafc0fb684bebb410`
- dist/index.html: `baad256ef77f977e422d864fb56a2124e8395ab5`

적용기 그대로 dry run 통과(구문 및 제스처 바이트 보존 포함) 후 --apply 실행. 이후 PR용 별도 브랜치에 커밋한다. main, Cloudflare 설정, 기존 문서, 원본 ZIP은 변경하지 않았다. 배포 명령은 실행하지 않았다.

## 유지 및 미검증

기본은 관찰만이며 자동/끄기 선택은 다음 판부터 적용된다. 자동 새 판은 ×1로 시작한다. CONTROL 16 제스처 구간은 바이트 그대로 보존했고 CSS, NOVICE 7 엔진/상수, BLOCK ITEMS V2 원본은 수정하지 않았다. 점수 증가 아이템은 복원하지 않았다.

미검증: 실제 휴대폰 멀티터치/입력 지연/성능, 장시간 실제 플레이와 자연 게임오버, 실제 플레이 중 자동 가속/완화 체감, 사람 실력 판정 정확도, 7분 생존과 재미, 배포된 DEV 환경. 자동 주기 조절 경계는 모듈/포트 테스트로 검사했으며 브라우저 장시간 플레이 증거는 아니다.

패키지의 승인 기획, 구현 인계 문서, 원본 테스트 로그 및 미완료 체크리스트는 내용 변경 없이 보존했다. 이 문서는 추가 검증 증거이며 기존 미검증 항목을 일괄 완료 처리하지 않는다. main 병합·자동 병합·운영 배포는 이번 작업에 포함되지 않는다.
