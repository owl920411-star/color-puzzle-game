# ADAPTIVE V1 STABLE — 세 묶음 안정화 기준

기준 코드: PR #7, `fd3b4983108997c165945fae5e3fe406e0dd76b5`.
이번 사용자 승인 범위는 **판단 기록 / 설정·결과 화면 / 기존 조절 규칙 안전성**의 세 묶음이다. 난이도를 더 낮추거나 새로운 아이템·AI를 넣는 작업이 아니다.

## 1. 판단 기록

새 `dist/adaptive-audit.js`는 기존 Director를 상속해 기록만 추가한다. `dist/adaptive-director.js` 원본은 수정하지 않는다. 최초 위험 감지, 제안 생성, 취소, 다음 지반 주기에 반영된 시각을 구분한다. 제안에는 고유 번호와 제안 당시 이유를 저장하고, 적용 시점에는 당시 판단 상태를 별도로 저장한다. 따라서 아이템 효과가 중간에 발생해도 이미 생성한 제안의 이유를 덮어쓰지 않는다.

제외 표본은 유효 입력 없음, 너무 짧거나 긴 배치 시간, 배치 중 긴 프레임, 프레임 보호 구간, 아이템·유물 영향으로 구분한다. 대표 사유 집계의 합은 제외 표본 수와 같고, 중복 사유는 별도 집계한다. 이 기록은 새 플레이부터 수집한다. 과거 진단에 없는 이유를 소급해서 만들어 넣지 않는다.

대기는 다음 전체 주기, 30초 재관찰, 새 배치량, 회복 구간별 상한, 선택 성향의 범위 등을 각각 표시한다. 여러 제한이 동시에 적용될 수 있으므로 하나의 원인으로 단정하지 않는다. 새 진단 사건은 최근 240개로 제한하고 잘린 개수도 표시한다.

게임오버 직전 실제 종료 경로를 기록한다: 새 블록 생성 충돌, 보관 교체 충돌, 지반 상승 중 상단 넘침, 지반 상승 후 조작 블록 배치 불가. 직접 QA 종료 등 경로를 모르는 경우는 unknown이다. 실제 보드와 지반 시도 보드를 분리해 남긴다. 이것은 종료 조건이지 플레이어 실수·게임 불공정성·근본 원인의 자동 판결이 아니다.

## 2. 화면

진행 중에는 ‘현재 판 진단’, 종료 후에는 ‘지난 판 결과’를 보여주며 다음 판 설정은 별도 구역에 둔다. 메뉴가 기본 게임 시계를 0으로 되돌려도 지난 판 아래에 새 판의 180초 카운트다운을 붙이지 않는다. 지반 정보는 ‘마지막 예약: 기본 38초 → 실제 39.9초’처럼 초 단위로 표시한다. 이는 마지막 주기이지 전체 판의 난이도 감소율이 아니다.

관찰 모드의 제안 확정과 실제 자동 조절 적용도 구분한다. ‘관찰 신뢰도’는 ‘판정 자료 충족도’로 바꾸며, IQ나 검증된 판정 정확도와 무관함을 명시한다. 복잡한 표본·이력은 접어서 표시한다. 설정의 작은 글씨 버튼을 눈에 띄는 일반 버튼으로 바꾸고, 게임오버 화면에서도 바로 지난 판 분석을 열고 같은 결과 화면으로 돌아오게 한다.

종료된 보고서를 복사해 보존한다. 내보낸 JSON은 종료 후 `current: null`, `lastResult`와 `history`는 동일 ID이면 한 판이라는 안내를 포함한다. 기존 프로필 버전과 기록 키는 보존한다. 새 진단 스키마만 `adaptive-audit-v1.1`로 구분하며 기존 최고점·프로필을 초기화하지 않는다.

## 3. 변경하지 않은 범위

CONTROL 16 오른쪽 UI, 큰 즉시하강, 제스처 처리 구간, NOVICE 7 기본 지반·낙하 수치, BLOCK ITEMS V2, 점수, 자동 조절 임계값·전체 상하한·쿨다운은 유지한다. 점수 증가 아이템을 복원하지 않는다. 이미 예고한 상승 시각을 바꾸지 않고 다음 새 주기에서만 조절하는 규칙을 그대로 사용한다. `main` 수정이나 병합은 하지 않는다.

## 4. 이번에 실제 실행한 검사

실행: `node --test tests/adaptive-director.test.cjs tests/adaptive-bridge.test.cjs tests/adaptive-stable.test.cjs`

**96개 통과, 실패 0**: 기존 모듈/브리지 52개 + 신규 안정화 44개.

신규 검사에는 모든 모드 3종 × 성향 3종에서 각 450개 합성 배치 흐름을 원본 Director와 비교하는 9개 검사가 있다. 비교 과정에서 실제 반환 주기, 판단, 제안, 회복 예산, 쿨다운 관련 값이 일치했다. 이것은 4,050명의 플레이나 4,050판 실전이 아니라 동일 입력에 대한 변경 전후 비교다.

실제 일반 엔진·블록 아이템·앱 컨트롤러와 연결한 테스트로 종료 경로, 결과 복귀, 메뉴 초기화, 다음 판 설정, 6종 아이템 점수 보존, 정지 중 시계 보존, 포인터 제스처를 확인했다. 이때 DOM·캔버스·스케줄러는 테스트 대체물이며 모래 엔진은 새 하네스에 로드하지 않는다. 기존 블록 연산 함수를 사용하는 무작위 보드 3,000개 회귀 검사도 포함한다.

이전 Codex의 117개 통합 검사 전체를 이번 변경에 다시 실행한 것은 아니다. 기존 테스트 파일은 삭제·약화하지 않는다. 이번 96개 결과와 이전 117개 결과를 합쳐 전부 최신판 검사인 것처럼 표시하지 않는다.

Chromium에서는 새 Bridge 진단·설정 UI를 실제 패널 스타일의 발췌본과 합성 게임 포트로 실행했다. 화면 크기 320×700, 390×844, 1280×900에서 오류 0, 가로 넘침 없음, 현재/지난 판 구분, 종료 후 JSON current null을 확인했다. 이 검사는 게임 전체 렌더링이나 실제 휴대폰 테스트를 대체하지 않는다.
